# root-records-vectors.json
Produced by bft-core `rootrecords` (branch p85/pr1c-import, commit 83f7cfb53799d6e9eb2751f1b2d709af40995038, `ROOTRECORDS_UPDATE=1 go test ./rootrecords`).
Do not edit by hand; regenerate and copy. Replayed by `AuthenticatedRecords.t.sol`: every record verbatim except the digest words of Closure and
Retirement, which the projection holds as opaque labels and the test replaces with custody-derived words (re-linking the chain) until the digest
formulas are shared.

UC time: the times in these vectors are quorum-approved wall-clock times of the root seal, bounded by root consensus (monotonic against the
parent, 30 s voter clock skew: ristik/bft-core#445, merged in ristik/bft-core#447) and imported monotonically on one lineage (bft-core `rootrecords.Clock`).

# custody-digests.json
Generated by custody itself (`CustodyDigests.t.sol`; `P85_WRITE_FIXTURES=true forge test --match-path test/p85/CustodyDigests.t.sol`), and the
test fails when the committed copy differs from what custody produces. Custody is normative for these words: bft-core's
`evmassign.AssignmentExposureDigest`, `KeyHistoryDigestFromHashes`, `ExposureID` and `ExposureChainStep` must reproduce them from the frozen
identity records (bft-core `evmassign/testdata/custody-digests.json` is a copy).

# state-slots.json, registry-state-slots.json
Generated by `StateSlots.t.sol` (custody) and `RegistryStateSlots.t.sol` (registry); regenerate with `P85_WRITE_FIXTURES=true forge test`,
which both tests compare against on every run. They record, per scenario, the storage slots the EVM itself reads for the public getters the
root authenticates with Ethereum storage proofs for a Retirement and a RejectResult (`vm.accesses`), their words, and the facts custody's
getters report. bft-core's `rootchain/evmstate` derives every slot from the declared layout and must land on the recorded one
(`testdata/` there holds copies). The custody scenarios use the test mock as `roots`; bft-core pairs them with registry storage built from
the registry fixture's slot rules.
